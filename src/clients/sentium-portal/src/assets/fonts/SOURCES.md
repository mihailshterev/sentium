# Font sources

Every file here is copied unmodified from the typeface's official GitHub release; only `SpaceGrotesk[wght].woff2` was
renamed to `SpaceGrotesk-Variable.woff2`, and Inter's `LICENSE.txt` to `OFL.txt`. All three are licensed under the
SIL Open Font License 1.1 with no Reserved Font Name; the licence text from each release sits next to its fonts.
The releases' author lists are not copied: the copyright line in each `OFL.txt` credits the project's authors and
links to the upstream repository, which is what the licence requires.

To update a font, download the new release archive, check its SHA-256, copy the same files out of it, and update
the tables below.
